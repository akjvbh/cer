# 已知坑

这些是同类项目真实踩过的坑。写代码时直接按这里的做法来，不要重新发明。

## Office COM 自动化

- `pythoncom.CoInitialize()` 必须在**每个用到 COM 的线程**里调用，用完 `pythoncom.CoUninitialize()`
- 同一时刻只允许一个 Office 任务：用全局 `threading.Lock` 串行化，不要让并发请求各起一个 WINWORD
- 每次转换设超时（默认 600 秒，读 `OFFICE_TIMEOUT_SECONDS`，演示时设 120）。超时后执行 `taskkill /F /IM WINWORD.EXE`（同理 EXCEL / POWERPNT），把这次转换标记为失败
- Office 不可用的判定不要靠「启动 Word 试试」：`/api/health` 用**注册表或可执行文件探测**（`winword.exe` 是否存在 / COM 类是否已注册），不要为了探活拉起一个 Word 进程。真正需要 COM 时再懒加载
- 不可用时的行为按文件类型分两类：
  - `docx → pdf`：切纯 Python 兜底排版，结果带 `note` 说明，**不要 500**
  - `.doc / .ppt / .pptx → pdf/png`：**明确报错**「本机 Office/PowerPoint 不可用，该格式需要 Office」，界面同时标记该功能「需要 Office」。不要退回一个内容残缺的 PDF 冒充成功
- 转换前把文件复制到临时目录，用绝对路径打开（中文路径、空格、只读属性都会出问题）；`DisplayAlerts = False`、`Visible = False`
- Office 跑过一次后要主动 `Quit()`，对象置 `None`，否则 WINWORD.EXE 残留

## 页码与旋转

- 统一 1-based、原文件页码。前端输入框旁边写「按原文件页码」
- `rotations` 传的是**最终角度**，直接覆盖原 rotation，不是叠加；前端把每页的当前角度累加好再提交
- 原文件本身带 rotation 时，预览要把 rotation 返回给前端，界面按这个角度初始化，否则缩略图是歪的、用户又转一次就错了
- `page_order` 非空才是白名单；空数组 = 没传，此时 `delete_pages` 生效
- 先删页/重排，再旋转；翻译覆盖层最后写

## 上传与安全

- 大小上限读环境变量（默认单文件 200MB、批量 500MB、最多 200 个文件）。判断要在**落盘之前**（读 `Content-Length` 或分块累计），不要先存完再报错
- 扩展名白名单 + 文件头 magic number 双校验（PDF 判断 `%PDF`，docx/xlsx/pptx 判断 `PK\x03\x04`）
- 加密 PDF：`fitz.open()` 后 `doc.needs_pass` 为真就直接报「不支持加密 PDF」，不要尝试空密码、不要继续处理
- 下载路径只能由 `task_id` 查表得到，**禁止**把用户传入的任何路径拼进文件系统
- 服务默认只监听 `127.0.0.1`；README 必须写明「无鉴权、无 HTTPS，仅本机或可信局域网使用」

## 输出编码与小细节

- `txt` / `csv` 输出用 **UTF-8 带 BOM**（`utf-8-sig`），否则 Excel 和记事本打开中文会乱码
- 多 sheet 的 `xlsx/xls → csv`：打包 ZIP，一个 sheet 一个 CSV，文件名 `<原名>_<sheet名>.csv`
- 多帧 GIF / 多页 TIFF：只处理第一帧/页，结果里 `note` 说明「仅处理了第一帧」，不要报错也不要静默丢弃
- 图片转 JPG 前先把透明通道铺白底，否则透明区域会变黑
- `md → html` 要开 `tables` 和 `fenced_code` 扩展，否则表格和代码块是纯文本

## 性能与内存

- PDF 预览只渲染前 50 页（长边 260px 的 PNG）；超过 50 页的部分在保存时原样拼接回去，不能丢页
- PDF 逐页转 JPG 的 300KB 是**硬指标**：先 150 DPI / quality 95，超了就降 quality（95→85→75→65），再降 DPI（150→120→96→72），最低档仍是 quality 50；到 `72 DPI + q50` 仍超就判该文件失败并说明原因，不要无限降、也不要静默超限
- PDF 压缩是重渲染，会丢文字层：**提交前弹确认框**，结果卡片的 `note` 里再写一次
- 批量任务用 `ThreadPoolExecutor(max_workers=4)`，但 Office 任务必须进串行队列
- 一次请求结束就释放 `fitz.Document`、`PIL.Image`、openpyxl 工作簿，不要留全局大对象缓存
- 缩略图不要渲染原尺寸；50 页 × 1600px 的 PNG 会把内存吃光

## 前端

- 文件选中后立刻显示文件名、大小、状态；失败要显示失败原因，不能只变红
- 长任务显示后端给的真实进度，不要用定时器假装 30% → 90%
- 切换功能标签时保留已选文件（状态放全局 `state`），不要切换就清空
- 整文件夹里格式混杂时，按源格式分组、每组各自选目标格式，分组并行提交，不要强行用一个 target
- 拖拽区域要同时支持「点一下选文件」和「拖文件夹进来」

## Windows 与启动

- `start.bat` 要处理三件事：没有 `.venv` 就创建并装依赖；缺依赖就补装；8000 被占用就自动换 8001 并打印实际地址
- 用 `.\.venv\Scripts\python.exe main.py` 启动，不要依赖 PATH 里的 `python`（Windows 上它可能是 Microsoft Store 的占位程序）
- 批处理文件用 CRLF 换行，`chcp 65001` 后输出 UTF-8
- 路径拼接统一用 `pathlib.Path`，不要用字符串 `+`

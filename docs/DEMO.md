# 5 分钟现场演示脚本

演示前先读一遍「翻车也不怕」和「10 分钟准备清单」。本脚本按观众最容易看懂的顺序排，不按开发顺序。

## 时间轴

### 0:00–0:30 开场：说明解决什么问题

- 动作：浏览器停在工作台首页，不要切标签。
- 屏幕：左侧「格式转换 / 批量处理 / 压缩 / PDF 工具 / AI 增强」，中间上传区，右侧空结果卡。
- 台词：
  > 日常办公里，格式转换、压缩、合并 PDF 这些事经常要做，但很多工具要求把文件传到别人的服务器。这个工具解决的就是这件事：除了你自己配置的翻译接口，所有文件都在本机处理，不上传第三方。

### 0:30–1:00 展示入口与隐私边界

- 动作：鼠标依次划过五个功能，停在「AI 增强」的「文献翻译」区域。
- 屏幕：翻译区域如果没配 key，会显示「未配置密钥」和配置说明；其他功能均可点。
- 台词：
  > 双击 start.bat 就能启动，默认只监听 127.0.0.1。转换、压缩、PDF 编辑、扫描件增强都不联网；只有文献翻译会把提取出的文字发到你自己的 OpenAI 兼容接口，密钥只放在本机 .env 里。

### 1:00–1:40 单文件转换：DOCX → PDF

- 动作：点「格式转换」→ 把 `samples\示例_项目说明.docx` 拖进上传区 → 目标格式选 `pdf` → 点「开始转换」。
- 屏幕：出现真实进度条；完成后右侧出现结果卡，显示文件名、大小和下载按钮。装有 Office 时调用 Word；没有 Office 时结果卡多一行降级说明。
- 台词：
  > 选文件后只列出这个格式真正支持的目标。转换是异步任务，进度来自后端，不是定时器假装的。结果直接下载，原文件不动。

### 1:40–2:10 批量处理：一次拖多个文件

- 动作：点「批量处理」→ 一次拖入 `samples\示例_项目说明.docx` 和 `samples\示例_文本.txt` → 按源格式分组各选 `pdf` → 点「开始批量处理」。
- 屏幕：文件列表显示每个文件的状态；完成后可以下载 ZIP，也可以单独下载某个成功文件；失败项单独标红并给出原因。
- 台词：
  > 批量不是简单循环：按源格式分组，各自选目标，组内并行，单个坏文件不会中断整批。失败项还能单独重试。

### 2:10–2:40 压缩：图片体积对比

- 动作：点「压缩」→ 拖入 `samples\示例_扫描照片.jpg` → 选 `40` 档 → 点「开始压缩」。
- 屏幕：结果卡显示压缩前后体积和节省比例。若选 PDF，会先弹确认框，说明压缩后文字层会丢失。
- 台词：
  > 压缩只做 PDF 和图片，四档体积目标。PDF 压缩是整页重新渲染，会丢文字层，所以提交前必须确认，结果卡里还会再提示一次。

### 2:40–3:40 PDF 页面编辑与撤销

- 动作：点「PDF 工具」→ 拖入 `samples\示例_论文.pdf` → 等缩略图出现 → 勾选第 2 页 → 点「删除选中」→ 按 `Ctrl+Z` → 勾选第 1 页 → 点「复制选中」→ 点「应用并下载」。
- 屏幕：删除后页数减少；`Ctrl+Z` 后页面恢复；复制后同一页出现两次；下载结果卡显示最终页数。
- 台词：
  > 页码全部按原文件算，1-based。删除、旋转、重排、复制共用一套撤销栈，最多 50 步，Ctrl+Z 撤销、Ctrl+Shift+Z 重做。复制页不是假预览，导出时真的会多出一页。
- 可选加一句：超过 50 页只渲染前 50 页缩略图，但保存时其余页面原样保留，不丢页。

### 3:40–4:20 扫描件增强（有翻译 key 时加 20 秒翻译）

- 动作：点「AI 增强」→ 在「扫描件增强」拖入 `samples\示例_扫描照片.jpg` → 等待结果。
- 屏幕：左右或上下对比原图与增强图；结果卡说明是否检测到纸张边界、是否做了透视矫正与去阴影。
- 台词：
  > 手机拍的纸经常是斜的、有阴影。这里自动找四角、透视矫正、去阴影、增强对比度；找不到边界时按原图轻微裁边，不会直接报错。
- 如果已配置翻译 key，再花 20 秒：在「文献翻译」拖入 `samples\示例_英文摘要.pdf`，选「中英对照」，点「开始翻译」。如果没配 key，不要现场配置，直接说：
  > 翻译需要本机 .env 里配置你自己的接口密钥；现在展示的是未配置时的禁用态和配置提示，避免把密钥带进演示环境。

### 4:20–4:50 技术亮点

- 动作：不用切页面，指着界面说。
- 台词（按 40 秒控制）：
  > 四个技术点。第一，本机处理，文件不经过第三方，翻译也只走你配置的接口。第二，Office 不可用时，DOCX 转 PDF 自动切内置排版并明确提示；.doc/.ppt 这种必须依赖 Office 的格式直接报错，不假装成功。第三，页码语义统一按原文件 1-based，先删页/重排再旋转，复制页用白名单重复页码实现，测试里专门锁了这些规则。第四，保留版式翻译是把译文写回原文字块矩形，不是重新排版，超出矩形会缩字号并截断。

### 4:50–5:00 收尾

- 动作：回到首页或 README 的测试章节。
- 台词：
  > 项目带三个可独立运行的自检脚本， smoke 覆盖 56 项真实 HTTP 流程；README 里写了已知限制和本机部署方式。所有文件处理都在本机，服务只监听 127.0.0.1。

## 翻车也不怕

| 现场情况 | 你该做什么 | 你该说什么 |
| --- | --- | --- |
| Office 转换卡住或 Word 弹窗 | 不要等。按 `Ctrl+C` 停服务，设置 `OFFICE_ENABLED=0` 后重启；DOCX→PDF 会走内置排版 | “这台机器的 Office 自动化不稳定，我切到不依赖 Office 的兜底链路，DOCX 仍能转 PDF，只是版式会有差异。” |
| 翻译按钮是灰的 | 不要现场填 key，直接展示禁用态和提示 | “翻译需要本机配置自己的接口密钥，演示环境没有放密钥；其余功能不联网，照常可用。” |
| 端口 8000 被占用 | 双击 `start.bat`，它会自动试 8001–8005 并在窗口打印实际地址 | “启动脚本会自动换端口，实际地址以窗口为准。” |
| PDF 缩略图很慢 | 继续讲页码语义，等结果；不要反复点 | “长文档只渲染前 50 页缩略图，保存时仍保留全部页面。” |
| 某个文件转换失败 | 点开错误详情，展示中文原因；换 `samples` 里的另一个文件 | “失败会明确说原因，不会返回一个空文件；批量里失败项也不会影响其他文件。” |
| 浏览器页面空白 | 看 `_start_log.txt`；确认服务窗口还在；刷新一次 | “启动日志在项目根目录，能定位是环境、依赖还是端口问题。” |

## 演示前 10 分钟准备清单

- [ ] 双击 `start.bat`，确认窗口里的实际地址，记在便签上。
- [ ] 浏览器只留一个标签页，缩放 100%，关掉无关扩展；主题切到深色。
- [ ] 关闭所有 Word / Excel / PowerPoint 窗口，避免 Office COM 抢焦点。
- [ ] 先手动跑一遍 `示例_项目说明.docx → pdf`，确认 Office 状态；不稳定就设 `OFFICE_ENABLED=0` 重启。
- [ ] 如果演示翻译：确认 `.env` 里 key 有效、余额够，先用 `samples\示例_英文摘要.pdf` 跑一遍，记住耗时。
- [ ] 准备好 `samples\` 下的：`示例_项目说明.docx`、`示例_论文.pdf`、`示例_扫描照片.jpg`、`示例_英文摘要.pdf`、`示例_文本.txt`。
- [ ] 跑一遍 `python tests\smoke.py`，确认 56 项全绿。
- [ ] 手机热点作为备用网络（只有翻译需要联网）。
- [ ] 录一份 5 分钟备份视频，现场崩了直接播。
- [ ] 把本脚本打印或放在第二屏，不要临场想词。

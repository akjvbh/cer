我要参加一个比赛，规则是必须用 Qoder 从零做出一个可运行的软件。我要做的是：**一个跑在 Windows 本机的办公文档转换器**，FastAPI 后端 + 原生 JS 前端，双击 `start.bat` 启动，浏览器打开就是完整界面。文件只在本机处理，不上传任何第三方服务器（唯一例外是「文献翻译」调用我自己配置的大模型接口）。

## 产品范围

### 1. 格式转换
单文件与批量转换，支持整文件夹。映射关系：

- `docx` → pdf, txt, html
- `doc` → pdf, docx（走本机 Word，Word 不可用时明确报错）
- `xlsx` → pdf, csv；`xls` → xlsx, csv
- `pptx` → pdf, png；`ppt` → pdf
- `pdf` → docx, txt, png, jpg
- `csv` → xlsx
- `md` → html, pdf
- `txt` → docx, pdf
- 图片互转（png/jpg/jpeg/webp/bmp/gif/tiff），以及 图片 → pdf、图片 → docx（嵌入）

### 2. 压缩
四档压缩（`80`/`60`/`40`/`20`），选文件后可以先「预估」四档压缩后的大小再决定。PDF 通过重渲染为 JPEG 实现（会丢文字层，界面必须提示）。

### 3. PDF 工具
- 合并：顺序合并、逐页交替、插入到指定页之后
- 页面操作：删除页、旋转页、重排（含复制某一页）
- 逐页导出 JPG，每张不超过 300KB，打包 ZIP
- 编辑器里显示页面缩略图，支持选中删除、旋转、拖拽排序后提交

### 4. AI 增强
- **文献翻译**：PDF / DOCX / TXT 逐段翻译，输出中英对照 DOCX、纯译文 DOCX、或保留原版式的 PDF（在原文字位置覆盖译文）
- **扫描件增强**：手机拍的照片自动找纸张四角 → 裁切 → 透视矫正 → 去阴影 → 增强为扫描件
- 术语表：项目根目录 `glossary.txt`，每行 `英文=中文`，翻译时自动带上

### 5. 工程与体验
一键启动、失败文件单独列出并可一键复制错误详情、真实进度条、深色/浅色主题、响应式布局、页面操作支持 `Ctrl+Z` 撤销。

## 技术约束（不得替换）

- 后端 Python 3.10+ / FastAPI / uvicorn；前端原生 HTML+CSS+JS，**不允许任何前端框架、npm 依赖或构建步骤**
- PDF 用 PyMuPDF；PDF→Word 用 pdf2docx；Office→PDF 用 pywin32 COM（可选能力，不可用时降级）；图片用 Pillow + opencv-python-headless；Word 生成用 python-docx；Excel 用 openpyxl
- 不引入数据库、Redis、Celery；任务状态放进程内字典
- 目录结构：
  `main.py`（路由/校验/任务表/下载）、`converter.py`（转换与压缩）、`pdf_tools.py`（PDF 工具）、`translator.py`（翻译）、`scanner.py`（扫描件增强）、`static/{index.html,app.css,app.js}`、`tests/smoke.py`

## 必须遵守的关键设计（这些是踩过坑之后的结论，不要改动）

1. **所有页码 1-based，且指原文件的页码**；`page_order` 同时是白名单（没列出的页丢弃），重复页码 = 复制该页，空数组 = 保持原顺序
2. **旋转是绝对角度**（0/90/180/270），不是增量
3. 标注坐标原点在页面左上角，单位 PDF 点；标注在删页/重排/旋转**之后**写入
4. 耗时操作立刻返回 `task_id`，前端轮询 `GET /api/tasks/{task_id}`；下载统一走 `/api/download/{task_id}`
5. Office COM 必须串行（全局锁）+ 超时（默认 600 秒，超时 kill WINWORD/EXCEL/POWERPNT）；Office 不可用时不报 500，而是降级并返回 `note`
6. 上传要校验扩展名白名单 + 文件头 + 大小，落盘文件名用 uuid，禁止用户提供路径参与拼接
7. 无 Office 的机器上，`docx → pdf` 用纯 Python 兜底排版（PyMuPDF 的 `insert_htmlbox` 或 reportlab 都可以），结果带 `note` 说明版式可能有差异

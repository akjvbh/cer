目标：在这个空目录里交付一个可运行的本地办公文档转换器（FastAPI + 原生 JS），我自己会双击 start.bat 演示。

以下是完成标准，你可以自主规划、迭代直到全部满足，每轮结束汇报进展和下一步：

1. `.\.venv\Scripts\python.exe main.py` 能启动，浏览器打开 http://127.0.0.1:8000 看到完整界面（左侧功能导航 + 拖拽上传区 + 结果卡片，深色/浅色主题）。
2. 以下转换能用 curl 验证通过并下载到文件：docx→pdf、docx→txt、pdf→docx、pdf→txt、pdf→jpg、图片→pdf、csv→xlsx、md→html、txt→docx。
3. 支持批量：多选文件后一次提交，逐行显示成功/失败，失败清单可一键复制，支持只重试失败的。
4. 支持四档压缩并且前端能先预估压缩后大小；压缩 PDF 前提示会丢文字层。
5. PDF 工具可用：合并（顺序/交替/插入到指定页之后）、删除页、旋转页、拖拽重排、逐页导出每张 ≤300KB 的 JPG 并打包 ZIP。页码一律 1-based 且指原文件页码，旋转是绝对角度。
6. 文献翻译可用（OpenAI 兼容接口，读 .env 里的 TRANSLATE_API_KEY / TRANSLATE_BASE_URL / TRANSLATE_MODEL）：至少支持 DOCX 输出中英对照，配置缺失时界面明确提示而不是报错崩溃。
7. 扫描件增强：上传手机拍照的图片，输出裁切矫正、去阴影后的增强图。
8. `python tests/smoke.py` 全绿，覆盖上面主要接口。
9. README 写清快速开始、API 表、已知限制（无鉴权、仅 Windows、压缩丢文字层等）。

硬约束：
- 前端不允许任何框架/npm/构建步骤；不允许数据库和外部队列进程。
- 没装 Microsoft Office 时，除 Office 转 PDF 的精度下降外，其它功能都要可用，且界面说明降级原因，禁止 500。
- Office COM 必须串行 + 带超时 + 超时后结束残留 WINWORD/EXCEL/POWERPNT 进程。
- 每完成一个能跑的小功能就真实执行一次验证并贴输出，不要伪造测试结果。
- 每完成一个阶段提交一次 git。
